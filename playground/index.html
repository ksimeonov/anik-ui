ak-min-w-0 — the flex overflow fix

Both rows hold the same unbreakable string. Only the second one is contained, because a flex child's automatic minimum size is min-content until ak-min-w-0 overrides it. ak-row does this for its children automatically.

ak-min-h-screen vs ak-h-screen

Both read --ak-viewport-block (default 100dvb). The min- variant is the one you usually want: it fills the viewport but still grows for taller content instead of clipping it. Resize / scroll on a phone to see dvb track the browser chrome.

ak-min-h-screen — fills the viewport, grows if the content is taller.
