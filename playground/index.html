Page wrapper & layout tokens

ak-page caps width at --ak-page-max (75rem) with --ak-page-gutter side padding. Both are plain custom properties, overridable per element (D-041).

Container variants beat viewport variants

ak-col-lg-6 ak-col-c-lg-4

On a large viewport, narrow the frame below 640px and the box goes to half width (the viewport variant); widen it past 640px and the container variant wins with a third. @container blocks are emitted after every @media block, so at equal specificity the container variant takes precedence.

ak-fixed inside ak-cq — containment caveat

The README warns that an ak-cq element can become the containing block for position: fixed descendants. This frame is a live test: it shows what your browser does, next to a contain: layout control that always captures. Run it in every browser on the support matrix, including the floor versions.

ak-measure + ak-flow

A readable column

ak-measure caps the line length at 65 characters, where long-form text is comfortable to read. ak-flow puts the same space between each direct child, whatever the elements are.

The flow space is 1em, resolved on each child, so it scales with the text it follows.

This paragraph has ak-mt-2xl: spacing utilities override the rhythm, because ak-flow is emitted before them.

ak-min-w-0 — the flex overflow fix

Both rows hold the same wide <pre>. A flex child's automatic minimum size is its min-content width, so without ak-min-w-0 the main region refuses to shrink and the row overflows (the dashed frame scrolls to show it). With it, the main region takes its share and the <pre> scrolls. ak-row does this for its children automatically.

Without ak-min-w-0 — the row overflows:

Sidebar
const config = { breakpoints: { sm: "576px", md: "768px", lg: "992px", xl: "1200px" }, containerBreakpoints: { "c-sm": "320px", "c-md": "480px", "c-lg": "640px", "c-xl": "800px" } };

With ak-min-w-0 — the pre scrolls:
