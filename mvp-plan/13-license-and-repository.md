# License & Repository

## License

Use the MIT License.

It matches the goal of a broadly reusable utility library and permits:
- commercial use
- modification
- distribution
- private use

The copyright and license notice must remain in distributed copies.

## Repository visibility

A public repository is recommended for this project because it:
- matches the open reusable-library goal
- provides transparent source/documentation
- supports issues and releases
- allows consumers to inspect the implementation

A private repository is technically compatible with a public npm package, but that would reduce the open-source value.

## Recommendation

Public Git repository + public npm package + MIT license.

## Public repository requirements

A public repository needs more than source. Phase 1 must add:

```text
README.md              install, imports, browser support, import order, API reference
CONTRIBUTING.md        branching, Conventional Commits, PR-title rule, local setup
CODE_OF_CONDUCT.md     Contributor Covenant
LICENSE                MIT
CHANGELOG.md           generated by the release pipeline
.github/ISSUE_TEMPLATE/  bug report, feature request
.github/pull_request_template.md
```

### README must cover

- install and the four import paths (`css`, `css/min`, `reset`, `scss`)
- the **required import order** — reset, component styles, utilities
- the **browser support table** and the container-query degradation behaviour
- the `ak-cq` side effects (shrink-to-fit, margin collapsing, nesting; D-046)
- a link to the generated class reference (`api/classes.txt`) and the live playground
- the responsive-spacing escape hatch via `--ak-row-gap`

### Deprecation policy

Public class names are API. The removal process is defined in
[`01-product-and-naming.md`](01-product-and-naming.md) and must be linked from
`CONTRIBUTING.md`.

`SECURITY.md` is not required for a CSS-only package with no runtime.
